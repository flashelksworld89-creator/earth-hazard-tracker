SEASONALITY-ADJUSTED PATTERN REPORTcalculating expected vs observed
Observed event counts are compared with an expected background built from 6-hour astrology snapshots inside the same calendar months in which the events occurred. This controls for seasonal clustering. “Lift” is observed ÷ expected; values above 1.0 are overrepresented and below 1.0 are underrepresented. The z-score is a screening statistic, not proof of causation.
